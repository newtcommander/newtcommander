# Data Model: Hot Path Display Names and Custom Icons

**Feature**: 047-hot-path-names-icons · **Date**: 2026-08-02

## Entity: Hot Path entry (`CHotPathItem`, `src/mainwnd.h`)

One of 30 fixed slots (`HOT_PATHS_COUNT`). The struct gains one field; the
meaning of `Name` changes in memory (custom label only), while its on-disk
meaning is preserved (effective label — see contracts/registry-format.md).

| Field | Type | Meaning (new model) | Constraints |
|-------|------|---------------------|-------------|
| `Name` | `char*` (UTF-8) | Optional **custom display name**. Empty = unnamed → surfaces fall back to the path. | Trimmed via `CleanName()`; whitespace-only → empty (FR-005). Non-empty `Name` requires non-empty `Path` (FR-004). Length bounded by `MAX_PATH` as today. |
| `Path` | `char*` (UTF-8) | Directory path, `$` doubled for escaping; may contain `$(...)` variables. **Defines whether the slot is assigned** (non-empty ⇔ assigned). | Max `HOTPATHITEM_MAXPATH` (4×MAX_PATH); validated by `ValidateHotPath` on page confirm. |
| `Visible` | `BOOL` | Show in Change Drive menu (unchanged semantics). | Default TRUE. |
| `IconIndex` | `int` (**new**) | Gallery index 0–9; 0 = default (current shell32 bookmark icon). | Out-of-range → coerced to 0 on load. Default 0. Reset to 0 on slot delete (FR-013). |

### Invariants

1. Assigned slot ⇔ `Path` non-empty. (`Name` non-empty no longer implies
   anything about assignment; empty `Name` is a valid state of an assigned slot.)
2. `Name` non-empty ⇒ `Path` non-empty (enforced by settings validation, FR-004).
3. `0 <= IconIndex < HOT_PATH_ICON_COUNT` after load, always.
4. Empty slot = all of: `Name` empty, `Path` empty, `Visible == TRUE`,
   `IconIndex == 0`.

### Derived values (new `CHotPathItems` API)

| Helper | Returns |
|--------|---------|
| `GetDisplayName(index)` | `Name` if non-empty; otherwise `Path` with `$$` unescaped to `$` (the user-visible path text — identical to what quick-assign historically stored into `Name`). Single source of truth for FR-002/SC-003. |
| `GetIconIndex(index)` / `SetIconIndex(index, i)` | Gallery index accessor/mutator (setter clamps to valid range). |
| `GetUnassignedHotPathIndex()` | First slot (from index 10 up, as today) with empty `Path` (was: empty `Name`). |

### State transitions

| Operation | Name | Path | Visible | IconIndex |
|-----------|------|------|---------|-----------|
| Quick-assign (Ctrl+Shift+digit, Ctrl+Shift+=, directory-line assign; FR-011) | `""` (no longer auto-filled) | panel path (escaped) | unchanged (default TRUE for empty slot) | 0 |
| Settings: set/edit name | custom text (trimmed; may become `""`) | unchanged | unchanged | unchanged |
| Settings: pick icon | unchanged | unchanged | unchanged | chosen 0–9 |
| Settings: delete entry (FR-013) | `""` | `""` | TRUE | 0 |
| Settings: Move Up/Down (FR-012) | slot contents swap as one unit (all four fields) | | | |

## Entity: Predefined icon set (gallery)

Fixed, ordered, **append-only** list of 10 entries; the persisted `IconIndex`
refers to this order, so existing selections survive future gallery growth.

| Index | Source | Appearance |
|-------|--------|------------|
| 0 | shell32.dll resource 319 (runtime-loaded `HFavoritIcon`) | Current default bookmark icon — unchanged |
| 1–9 | `src/res/hotpath<1..9>.ico` (committed, generated by `tools/brand/gen_icons.py` from `tools/brand/hotpath-master.png`) | Original bookmark motif tinted: red, orange, yellow, green, teal, blue, purple, pink, gray |

Runtime representation: `HICON HHotPathIcons[HOT_PATH_ICON_COUNT]` (index 0
aliases `HFavoritIcon`), loaded at `IconSizes[ICONSIZE_16]`, reloaded on
DPI/color change alongside `HFavoritIcon` (FR-014). Asset frames: 16/20/24/32 px.

## Persistence mapping (summary — full contract in contracts/registry-format.md)

`HKCU\Software\Tandem Commander\0.1\Hot Paths\<1..30>` (subkey = 1-based slot;
legacy: subkey `"0"` read as slot 10):

| Value | Type | Write rule | Read rule |
|-------|------|-----------|-----------|
| `Name` | REG_SZ | Effective label: custom name if set, else the path text (legacy-compatible) | `Name == Path` → in-memory `Name = ""` (unnamed); else custom name |
| `Path` | REG_SZ | As today | As today |
| `Visible` | REG_DWORD | As today | As today |
| `Icon` | REG_DWORD | Only when `IconIndex != 0` | Missing/out-of-range → 0 |

Empty slot (Path empty + defaults) → subkey deleted, as today.
